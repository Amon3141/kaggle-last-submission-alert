# Kaggle 残り提出回数警告

Kaggle で「今日の提出回数が残り1回」のときに警告を表示する Chrome 拡張機能です。

## 機能

- 残り1回のとき、提出エリアに警告を表示・Submit ボタンクリック時に確認ダイアログを表示
